# Configuration examples

This directory contains deliberately incomplete templates only. They are not live exports and should not be used until each placeholder is reviewed.

The WireGuard example reflects related historical lab notes, but the attached Phase 1 evidence does not establish an active tunnel or current handshake. See [`../docs/networking-and-wireguard.md`](../docs/networking-and-wireguard.md).

Never replace placeholders with real private keys, OCI credentials, LDAP bind secrets, public IPs or complete live peer configs in a public repository.
