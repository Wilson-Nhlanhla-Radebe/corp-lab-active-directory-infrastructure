# Evidence screenshots

This directory contains ten original PNG screenshots, ordered by the evidence sequence in the [repository README](../README.md). Their binary contents match the selected files in the source archive.

The images show configuration and workflow examples from the time of capture. A share inventory does not prove effective permissions, and a folder ACL view does not establish what every user can access. The OCI image shows one network rule only. The LDAP test is historical evidence, not a live availability check. Ticket and offboarding images show individual examples, not complete automation.

Several GLPI screenshots retain a historical server IP and visible account names in the original captures. No credential was visible in the selected images during visual review; verify that displayed identities are synthetic before reusing the screenshots. The evidence does not establish current cloud availability.
