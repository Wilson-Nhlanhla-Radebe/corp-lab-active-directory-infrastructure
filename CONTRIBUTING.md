# Contributing / updating this portfolio lab

This repository documents an individual practice lab. Before changing it:

1. Verify the state of the actual lab.
2. Update the implementation-status table and test log.
3. Add only redacted evidence that demonstrates the stated result.
4. Review all changes for credentials, private identifiers, and personal data.
5. Never label a planned or unverified component as successfully deployed.

Starter scripts are provided for learning and require review before use. They are not a replacement for a tested change-management process.
